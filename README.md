Dumbbell Mean Curvature Flow

Python code accompanying The Neckpinch Threshold for Rotationally Symmetric Dumbbells: A Mean Curvature Flow Benchmark and Allen–Cahn Comparison.

The script reproduces the axisymmetric mean curvature flow simulations, numerical thresholds, validation tests, and Figures 1–3.

Requirements: Python 3, NumPy, Matplotlib

Install:

pip install numpy matplotlib

Run all experiments:

python dumbbell_mcf.py all

Results are saved to results.json.

Author: Kavin Krishna, Rice University.
